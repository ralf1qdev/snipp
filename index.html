How it works

Three steps. That's it.

Install in seconds

Run the installer — no admin rights, no restart. Snipp starts and waits in the notification area.

Press PrtSc

Drag a region or click a window. Your snip opens in the editor and is already on the clipboard.

Mark it up & share

Add arrows, text and blur, then paste it anywhere or save it. Undo everything, anytime.
